# 다온한방병원 웹사이트

React, TypeScript, Vite, Tailwind CSS v4로 제작한 반응형 한방병원 원페이지 웹사이트입니다.

## 실행 방법

```bash
pnpm install
pnpm dev
```

Figma Make 환경에서는 개발 서버가 자동으로 실행되므로 별도로 시작할 필요가 없습니다.

## 주요 기능

- 반응형 고정 헤더 및 모바일 메뉴
- 진료 분야별 상세 팝업
- 진료 예약 신청 폼 및 접수 완료 화면
- 병원 공간 이미지 확대 보기
- 공지사항 팝업, 전화 연결, 지도 연결
- 부드러운 섹션 이동 및 상단 이동 버튼

이미지 자산은 `public/images` 폴더에 포함되어 있으며, 배포 전 실제 주소·연락처·사업자 정보를 병원 정보로 교체해 주세요.
